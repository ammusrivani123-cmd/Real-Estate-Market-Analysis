
# Real Estate Market Analysis

## Project Overview
This Data Analytics project explores real estate
market data to identify property price trends,
market patterns, and important business insights.

## Objectives
- Analyze real estate market trends.
- Identify patterns in property prices.
- Perform Exploratory Data Analysis (EDA).
- Visualize relationships between variables.
- Generate meaningful business insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Business Insights

## Project Files
- eda pjct .ipynb: Analysis and visualizations
- eda pjct.pptx: Project presentation

## Conclusion
This project demonstrates how data analytics
can help explore real estate market patterns
and support data-driven decisions.
